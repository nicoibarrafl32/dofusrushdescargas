# DOFUS Rush 2 — Descargas

Cronómetro y guía de rush para DOFUS: rutas editables, kamas por personaje, búsqueda y captura,
y PNJ con su viaje (`/zaap` + `/travel`) a un clic.

## Descargar

**[Última versión](https://github.com/nicoibarrafl32/dofusrushdescargas/releases/latest)**

- **Windows:** `DOFUS-Rush-2-Instalador-Windows.exe` (no pide administrador).
- **Linux:** `DOFUS-Rush-2.AppImage` (dale permiso de ejecución).

Una vez instalada, la app se actualiza sola: avisa cuando hay versión nueva
(o en **Perfil → Actualizaciones**). Tu progreso, tus rushes y tu licencia no se tocan.

## Si Windows muestra un aviso

«Windows protegió su PC» → **Más información** → **Ejecutar de todas formas**.
Aparece porque el programa no tiene una firma comprada a Microsoft, no porque tenga un virus.
Puedes comprobar el archivo con `SHA256SUMS.txt` de cada versión:
`certutil -hashfile DOFUS-Rush-2-Instalador-Windows.exe SHA256`.
